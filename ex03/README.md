# Project 00 - Linux Git and GitHub

This project introduces the basic Linux terminal commands and Git version control.

## What I Learned

I learned how to navigate directories using the terminal
create and manage files
use Git to track changes
create commits
connect a local repository to GitHub
and push my work to a remote repository

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes made to a project

It allows developers to return to previous versions if something goes wrong

Git also helps developers work together because each person can track changes and share their work through repositories such as GitHub
